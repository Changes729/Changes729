### 二、图算法与图分析 自学资料推荐

1. **图算法推荐书籍与资料**
   - 《Algorithms, Part II》by Princeton（Coursera 免费课程）
   - 《Graph Theory with Applications》by Bondy & Murty
   - [《图论及其应用》（中文版）](https://z-library.sk/book/1131589/28a08b/%E5%9B%BE%E8%AE%BA%E5%8F%8A%E5%85%B6%E5%BA%94%E7%94%A8.html)，同济大学出版社
   - Stanford CS224W: Machine Learning with Graphs（图机器学习课程）
2. **学习重点**
   - 基本算法：DFS、BFS、最短路径（Dijkstra/Bellman-Ford）、最小生成树（Kruskal、Prim）
   - 高级算法：PageRank、社区发现（Louvain）、连通分量、图着色、匹配算法
   - 图分析库推荐：**NetworkX（Python）**、**GraphX（Spark）**、**Neo4j 图算法插件**



# 三、C++ 开源图处理库推荐

1. **Boost Graph Library (BGL)** [graph](https://github.com/boostorg/graph)
    功能全面，支持各种图结构与算法，是工业界和学术界广泛使用的图库。
2. **Lemon (Library for Efficient Modeling and Optimization in Networks)** [lemon](https://github.com/tpet/lemon)
    高性能图优化库，适合算法研究与教学用途。
3. **Networkit**
    主要用 C++ 编写，Python 可调用，专注于大规模图数据的并行分析。
4. **Graph-tool**
    使用 C++ 编写、Python 绑定，适合复杂图分析与可视化，支持很多图论算法。
5. **[SNAP (Stanford Network Analysis Platform)](https://snap.stanford.edu/)**
    C++ 开发的高性能图库，适合社交网络与大规模图分析。
