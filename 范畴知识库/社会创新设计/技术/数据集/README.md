## 数据库

> 参考资料：[DB-Engines Ranking](https://db-engines.com/en/ranking)

**01 数据库类型**

- 关系型数据库（Relational DBMS）：Oracle、MariaDB（MySQL）

- 键值对存储（Key-value stores）：Redis

- 文档存储（Document stores）：MongoDB

- 时间序列数据库（Time Series DBMS）：InfluxDB、[Prometheus](https://prometheus.io/)

  > [Grafana](https://grafana.com/)，监控前端

- 图数据库（Graph DBMS）：Neo4j

- 搜索引擎（Search engines）：Elasticsearch

- 对象存储（Object oriented DBMS）

- 向量存储（Vector DBMS）：Elasticsearch

- 资源描述框架存储（RDF stores）
