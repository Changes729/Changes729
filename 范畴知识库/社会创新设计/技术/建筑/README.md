# 建筑

## 关键词

- [BIM 5D](https://www.autodesk.com/solutions/5d-bim)（Building Information Modeling，建筑信息模型）：[广联达](https://www.glodon.com/)、[Autodesk Revit](https://www.autodesk.com/products/revit/overview?term=1-YEAR&tab=subscription)

  > Revit 是最常用的软件，对于几何构造的建筑会很容易建模，但是对于异形结构而言，会比较困难要借助 Dynamo 或者二次开发。

  如果说 CAD 把结构信息放在几千张图纸中，那么BIM就把所有信息放在一张图纸中。

- 天正建筑 TArch：基本流程包括，绘制轴网、改墙、加柱、门窗、楼梯。有个细节是墙厚240，轴线是根据墙体中心线绘制的。

  > 书中的版本为 V7，现在好像都要V9了

  - [天正建筑绘制轴网之直线轴网](https://www.bilibili.com/video/BV1mX4y1W7gx/?spm_id_from=333.337.search-card.all.click&vd_source=b736aa3d7f0fdf47b59ea3021dc810ab)：轴网上开下开、左进右进的介绍
