# 虚拟环境

## Install

- 安装 Docker：[docker](https://archlinux.org/packages/?name=docker) \ [docker-compose](https://archlinux.org/packages/?name=docker-compose)
- 启动服务（需要重启）
- 可能需要配置代理：https://docs.docker.com/engine/daemon/proxy/#httphttps-proxy



## Docker

- 进入容器：`docker container ls` 然后 `docker attach [i]`
- 重启容器：`docker container restart`
- 从镜像导入：`cat ros_melodic_builder_exported.tar.gz | docker import - ros-hilens1    (镜像名自己定义)`



## Docker file

- 构建镜像：`docker build . --tag [xxx]`
- 获取镜像：`sudo docker pull ubuntu:12.04`
- 列举镜像：`docker images`
- 运行镜像：`docker run [xxx]`
  - `--name`：命名 Container，`docker run --name test -d [images]`
  - `-v`：加载卷，`docker  run  -v $(pwd):$(pwd)`
  - 分离模式：`docker run -d -p 80:8080 [xxx]` 将镜像内的8080转到外部80
  - 启动镜像：`docker start`
- 查看容器：`docker ps --all`
- 进入容器：`sudo docker attach nostalgic_hypatia`
- 关闭容器：`docker stop [xxx]`
- 存储容器：`docker save -o my-image.tar my-image:latest`

> mac 上的 docker 需要通过application启动一下



## docker compose

- `docker compose up -d`
