# 树莓派 网络启动（PXE）

**01 获取树莓派 `/boot` 和 `/root` 目录**

**02 配置 TFTP 服务器**

一般配置 TFTP 服务器有两种办法，一种是在 DHCP 服务器上配置 Option 66，以让树莓派等客户端可以读取到 TFTP 服务器的 IP

另一种就是配置树莓派的 `TFTP_IP` 。



**03 服务器配置 TFTP / NFS 服务**

TFTP 服务器需要配置 boot 文件，NFS 服务需要同时挂载 boot 和 root

需要注意的是，NFS 的文件权限。笔者是使用 `nfs-utils` 作为 NFS 服务器，在配置时需要编辑 `/etc/export` 文件将指定目录对外开放

```
[...]/rootfs 				*(rw,sync,no_subtree_check,no_root_squash)
[...]/tftp/8c07b921f54101c2 *(rw,sync,no_subtree_check,no_root_squash)
```

其中，`rw` 表示文件可读写，客户端试图以根用户身份访问文件或目录，服务器会将该请求视为来自非特权用户。所以使用 `no_root_squash` 来取消 `root` 限制



**04 服务器修改 `bootfs/cmdline.txt` 和 `rootfs/etc/fstab`**

```shell
# bootfs/cmdline.txt
console=serial0,115200 console=tty1 root=/dev/nfs nfsroot=1.1.1.1:[...]/rootfs,vers=4.1,proto=tcp rw ip=dhcp rootwait elevator=deadline
```

```shell
# rootfs/etc/fstab
proc            /proc           proc    defaults          0       0
1.1.1.1:/tftp/bootfs /boot nfs defaults
```
