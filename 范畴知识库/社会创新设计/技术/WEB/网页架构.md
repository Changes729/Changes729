# 网页架构

## 关键词

- Domain Driven Design（DDD）：通过与专家沟通建立统一的语言，形成数据、工厂和业务模型，进而开始下一步开发

- Onion Architecture

  ![Onion Architecture illustrating different layers. Domain Model at the centre, enclosed by Domain Services. Domain Services enclosed by Application services and then Infrastructure Services. Application enclosing all the layers. Observability services for monitoring the application](https://miro.medium.com/v2/resize:fit:481/1*Pd6l7Za_Pl8BI-kltDQukg.png)

  从内到外：

  - Domain services：核心业务逻辑
  - Application services：用例，不包含具体业务逻辑
  - Infrastructure services：服务与外部进行交互
  - Observability services：如日志系统
