# CRM（Customer relationship management，客户关系管理）

CRM系统从一系列不同的通信渠道编译数据，包括公司的网站，电话（许多服务都配有软电话），电子邮件，实时聊天，营销材料和最近的社交媒体。它们使企业能够更多地了解他们的目标受众，以及如何更好地满足他们的需求，从而留住客户并推动销售增长。



## 业务流程

### 销售员的业务流程

**00 工作辅助**

- 日程提醒

**01 外围任务**

- **01.1 线索找寻**：线索是所有业务的开始。是可能的商机。这是**次要任务**，也被称为**客户海**。

  - 信息来源（网络、人）

  - 线索信息

  - 下一步工作（时间-内容）

- **01.2 市场对标**

  - 竞品价格比对

**02 主要任务**

- **02.1 合同（历史）**

  - **商机（客户）**：线索真实的转化为可能成交的商机。比如意向明确时。这是**主要任务**，也是考核的主要标准。
    - **客户信息**
      - 线索（历史）
      - 详细资料（客户信息、人员与联系方式）

  - ***商品信息***
    - 货物品类
    - 数量
    - 单价
  - 合同管理
    - 报价（审批）
    - 合同开具（审批）
    - 货物跟踪
    - 回款跟踪
    - 发票开具
