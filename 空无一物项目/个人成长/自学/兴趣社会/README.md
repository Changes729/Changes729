# 兴趣社会

## 需求和愿景

今天思考一个项目——兴趣爱好成本排布，本意是觉得现代人类缺少兴趣，所以想从低成本的兴趣爱好切入，组建一个基本兴趣爱好扫盲团，扩大当代人类兴趣面，以兴趣爱好重新连接人与人。同时可以引入各种文化沟通，学术研究。

正好今天也同时阅读了两篇文章，其中一篇提到了组织的成长：

> 有些大型科技公司，只招募中高级程序员，不招募初级程序员。我认为，这样做不对。
>
> 因为现代企业是知识型企业，初级程序员会迫使团队去教导、训练、合作，从而发现知识、创造知识。

还有一篇提到了欧洲战略自主。虽然还没有明确，但是三者之间的联系及重要性在我的感性认知下已经占据了大脑的全部。简单整理后觉得人类发展依旧可以从兴趣，到技能到生产力的步骤前进。

项目名称我称为——兴趣社会。相对的还有学习型社会、科技社会。

哦还有一个是关于学习势垒。比如诗歌发展到唐朝为鼎盛，但是某个潮流的鼎盛也意味着入局门槛极高。基本上只有打碎重来的可能。
