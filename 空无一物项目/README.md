## 项目流程

参考 Alluvial 禅思：需求和愿景、能力与资源、要素与路径、成果与不足。

空无一物项目流程为：<u>从过去到未来、从经验到流程、从生活到协作、从虚无生一物</u>，享受生活

与 Alluvial 个人的活动不同，空无一物项目具有社会性协作。因此，需要在理解所有人的 Alluvial 基础之上，进一步为协作提供机制。

当然，世界最大的共同目标目前不得而知，但是我们不应该回避冲突，各方都应该站在自身鉴定的立场上去寻求生存的办法。

## 空无一物梳理

【2025-06-10】

**01 个体**

个体的自驱力来源包括了自然和社会。其中，自然包括了「基因」和「大灾」，社会仅包含「意义」。

基本动力包括——「生存」「玩耍」「生育」和「安全」。

**02 社会协作**

个体通过沟通和协作促成社会集体，形成集体意识与集体实践。其集体行为分别满足社会集体内的个体的各个方面的需要。社会集体通过协同同力凝聚成员，通过协同斥力淘汰成员。社会集体具有集体知识和集体恐惧，具有责任转移等现象。

**03 社会协作的发展**

社会协作从最早的古典协作，面向自然的压力，人类自然选择的改造，外部压力需要人类进行协作，沟通和实践过程促进了人类生存与发展。内部需求如玩乐、生育和安全，则进一步构成了人类的改造力。

随着时代发展，因生产力限制，旧集体协作围绕知识形成了人类集群，但是自然的压力依旧存在。期间发展出了神学、分工和阶级。此阶段已经出现了部分物质丰度的集中，人类会主动促进物质集中。

时代继续发展，物质丰度不平衡，被动产生经济货币进行丰度平衡，促进了经济、金融发展。

**04 空无一物的概念**

空无一物回顾历史，立足当下，尊重个体的根本性需求，置社会性新需求以疑。针对当代社会商业协作范式的困境，立于社会个体，小型社会组织的生存立场，围绕个体成长，并创建促进新型社会协作。强调经济的劳动-生活的去金融的经济循环。
