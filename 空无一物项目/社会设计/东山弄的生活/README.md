# 东山弄的生活

## 缘起

受秋玲邀请，驻地东山弄为在地设计一款桌面游戏。倾向于老龄友好的游戏。

我经过两晚的深思熟虑，觉得可以设计一款全年龄组合型游戏。



## 理解

**01 东山弄的起源**

东山弄是杭州黄龙、玉泉、西湖交汇处。东北处为黄龙体育中心，东边为浙江图书馆和黄龙洞。南边为西湖，植物园、青芝坞。西边为浙大玉泉校区。

因此，东山弄的长居人群可推测为浙大老师、老杭州人，或是政府公务员。



东山弄市集由西湖城投投资建设，里仁商业负责建筑改造和市场运营，运营方再邀请Upbeing合作运营。



**02 东山弄的概况**

就布局来看，东山弄市集分为一期和二期。

一期主体为网红菜市场，上层是蔬菜、香料、豆制品等。下层是水果、生鲜和餐饮小铺。

二期主题为嵌入式的品质生活广场，外围有各种五金杂货铺和大型品牌餐饮，上层有旅店，中央围成了一个嵌入式广场。



从交通来看，东山弄只有东边一条通往西湖的外东山弄。地铁在东山弄以北约20分钟的路程。因此，东山弄市集的自然人流，大多为步行到此处的在地居民、浙大学生和来附近旅游的游客。



**03 东山弄往期运营实践**

东山弄二期计划建设以来，发掘了在地的「品质生活」「顺食同行」为意向的主题活动，符合东山弄片区的社会文化。



## 定义

**01 东山弄桌游可能性**

我们希望设计开发一款生活模拟桌游，将「品质生活」和其背后的人结合起来，再尝试将每个具体的人具象化。从而达到看见环境，看见自己的目的。



**02 桌游特性与要求**

1. 必须满足对小孩，老人友好。
2. 必须兼顾拓展性，可以为适当推广到其他市集。
3. 必须本地化。
4. 需要符合东山弄片区的生活文化，符合「品质生活」和「顺食同行」的意向。



**03 桌游目标**

1. 与本地市集联动，促进人与环境的连接
2. 促进游戏中的个体发展，通过游戏模拟进而产生对现实生活的影响
   - 小孩子：促进社会教育和自然教育
   - 家长：促进孩童教育认识，和老年人养护认识
   - 老人：促进智力运动和日常锻炼
   - 运营：促进识别区域运营机制



## 设计

**01 人群**

- 小孩
- 老人
- 家长



**02 行动力与游戏目标**

- 小孩的行动力来源于社交、玩耍。游戏目标因此也设定在社交和知识量。
- 家长的行动力来源于稳定的生活和对未来的期望。游戏目标也是帮助家庭过上美好的生活。
- 老人的行动力来源于健康生活。游戏目标就是生活幸福度。
