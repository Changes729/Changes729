# 零食（临时）创变局

## 需求和愿景

笔者作为「草台」活动的重要关注者，希望可以通过参与「草台」活动的全流程，促进活动的迭代和发展。

另外，因为「草台」活动背后理念的抽象复杂，而表现形式又无法进一步形成品牌印象——比如大家会认为是否类似艺术驻场创作，抑或认为是不是另类的黑客松。

但实际上「草台」活动的根本在于引导个体不要停留于开始想法，也不要害怕理想的好高骛远，而重在促进个体主动的行动过程。

因此，一方面为了关注与参与「草台」活动本身，另一方面也为了活动对象——活动参与者通过实践向更好的自己发展，笔者也发起一个草台项目——「临时创变局」。

其目的在于辅助「草台」活动，面向具体的活动对象，引导个体明晰自身的向往，明确并促进个体当下可能的行动。



围绕需求和愿景，现在重新梳理一下笔者的能力和资源。



## 能力与资源

**01 资金支持**

作为「草台」的重要关注者和参与者，可以从本人战略储备金中提供部分用于支持创变局。



**02 社会创新与理解能力**

笔者长期关注社会创新，因个人经历，自认为具有一定的共情理解能力。能一定程度上有效识别个体的动机、能力、行动路径和预期成果。可以站在社会创新的立场去理解个人，理解项目，并提供沟通交流的机会。

社会设计方法论参考中央美院的方法论：

- 历史作为方法——做真问题
- 行动作为方法——真做问题
- 设计作为方法——会做问题
- 批判作为方法——反思问题
- 网络作为方法——开放问题

创新设计则参考浙江大学的方法论：

- 创新五要素：人本、商业、艺术、技术、文化



**03 技术背景且具有项目经验**

笔者技术背景和项目经验，相应催生了技术思维和工程思维，对流程性落地执行的项目具有很好的演绎能力。

凭借项目经验，也可以促进对项目的跟踪、理解和评估。



**04 与主办方的良好合作关系**

笔者已经提前与主办方进行沟通，并获得了主办方的同意和支持。

主办方可以提供各项目草案和具体现场执行的项目行动者。



## 要素与路径

**01 触点**

项目与个体的触点很重要。如何拉低双方对于链接的期望，需要对触点进行设计——可以随时随地重新链接。



**02 项目库呈现**

可能创新一个想法对一些人而言会比较困难，活动发布初期也提供了很多参考案例。

临时创变局也应该搜集很多项目库用于激发个体灵感。



**02.1 创新想法记录**

配合项目库的扩充，如果真的激发了线下个体的创新，催生了新的创新想法，应该适时将新想法入库。



**03 项目跟踪**

对于现场已经在执行的项目，需要对其进行跟踪。同步项目进展情况，一方面为新人的理解和创新提供一手实践资料，另一方面则是为日后的项目和活动复盘搜集一手信息。



**03.1 项目促成**

个人的力量是有限的，临时创变局不只是草台项目的搬运工。

创变局应该回到创变的根本目的上，因此，创变局需要促进人与人的协作，让困难的实践在合作中降低壁垒。



**04 坚持草台班子精神**

遇到困难，不要害怕！微笑着面对他 : )



## 成果与不足

**01 零食创变局**

目前计划以「零食」作为触点媒介与人产生联系。可以以单纯的零食摊为主进行运营。

而且零食摆摊也需要进一步细化，买多少零食，怎么摆，如何定价都是需要推敲的问题。



**02 项目记录流程**

目前项目记录流程有一套记录规范。也可以由记录者根据自身喜好进行记录跟踪。

不过，记录过程需要人手，还是需要偷跑活动进行一定的招募。



**03 以创变局为媒介**

计划将创变局作为媒介向活动与个体敞开。

例如开展 ~~相亲活动~~ 志同道合交流会——即使短时间的执行落地存在些许困难，但是可以通过沟通交流，积累灵感，为日后的行动孵化积累能量。

再例如，能不能以创变局为媒介构成在地各零散的零食摊位的售卖终端？在零食创变局可以轻松购买到在地所有的零食（~~而且更便宜~~）

（...灵感保留）
