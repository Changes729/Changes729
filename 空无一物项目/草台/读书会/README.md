# 读书会

读书会最好的目标是「学以致用」



读书会赋能是「共学」系统中的一环。我们希望通过数字化赋能读书会活动。（活动的工具，反向依赖为活动的平台）

- 更个体友好的读书会类型匹配
- 更社区友好的读书会机制设计秘籍

可以在里面去寻找/发起读书会活动。

> 其实本质上是开放活动。



### 竞品

- 知识星球
- 和**小红书 Tag**不一样，我们希望读书形成个体的认知系统。
- 和**豆瓣小组**不一样，我们希望降低全社会的读书门槛。
- 和**微信读书**不一样，我们强调及时沟通和信息对齐的重要性。
- 和**活动行**不一样，我们赋能组织和知识在组织中的流转。



## 现有读书会类型分类

**00 未实践变体/案例缺失**

- 【00 经济化】：收取费用作为资金池，每次沟通将部分资金回馈给最佳贡献者。
  - 最佳贡献者的评价可根据读书会目标做相应调整。
- 【01 数字社群】：设立读书会制度，以制度开放促进社群构成；提供AI最接近社群，助力活动产生。



**01 短读会**

> 【案例一】来自 706 林冉
>
> 【案例二】本人设计分享会类似与此

特征：组织沟通交流的**短平快**形读书会

核心流程：第一天发布主题，随后一周自行根据主题进行读书（书籍、公众号、影视、音乐、文献等），周末举办读书会分享&交流会。

变体：暂无



**02 研读会**

> 【案例一】来自 706 林冉 ？
>
> 【案例二】点点读书会也类似与此

特征：带领阅读相关领域经典文献和资料，培养专业性、纲领性和框架性。

核心流程：由社群确定共读书籍，以一周为周期，一周内自行阅读，一周末进行线上、线下导读，专门阅读一些经典桥段，形成部分总结。提供后续回放。

变体：

- 【01 轻松化】：线上自由发言，会 Call 人。无回放，无总结。
