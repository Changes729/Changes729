# 个体成长与社会协作（行动村）

## 行动村的目标

行动村的目标是促进社会协作（行动）。其中包括了促进人与人的理解，促进人的行动效率，促进行动的积累、反思和传播。



### 名词说明

- 活动：社会个体自我或有组织的运动，每个人目的各不相同，但是可以在未形成目标共识的情况下对运动过程达成共识。
- 行动：社会个体围绕自我与社会的目标，在达成愿景共识的情况下的协同合作。
