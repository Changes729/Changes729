## 数据库

### Redis：应用缓存

从代码中的 `config/cache.php` 和 `config/database.php` 可以了解到，通过 Laravel 框架，配置了 redis 和 缓存。

> - `Cache::put('key', $value, $minutes)`: Store data for a specified duration.
> - `Cache::get('key')`: Retrieve data.
> - `Cache::remember('key', $minutes, function() {})`: Retrieve data or store it if not found.
> - `Cache::forget('key')`: Remove an item from the cache.
> - `Cache::flush()`: Clear the entire cache.

工程中几乎所有数据都是缓存。唯一持久化存储的是 `MiniappCode`
