# 草台班子 & 创变局复盘

## 愿景与初心

从理念上说，草台班子的初心是希望大家可以不要停留于想法。完成大于完美。

而创变局，则是草台班子的实践促生部分，其象征着，若是需要将草台班子落到实处，是需要通过实践的方式与人接触，促成创变的。

毕竟草台在哪里，也是需要吆喝的。



除了理念上的初心以外。

对于自己当然也是希望可以在事业上可持续。有没有可能形成商业循环？并且将草台作为一种社会的补偿——也就是个体成长与社会协作中缺失的部分。从而形成一种真正生于社会，长于社会的变革方案。



另外，从思路上看，目前我关注的两个方面——个人成长与社会协作部分，如果说以「自习、共学、教学」三模块构成的个人成长和以「行动村」为模块的社会协作之间，缺少一个桥梁，那么这个桥梁很可能就是「草台班子」。



可能还是想通过复盘会得出一些共识——我们对活动有哪些「期望」、对两天的实践有什么「收获和不满」、以及从自己的角度出发「下一步」可能能怎么走

## 能力与资源

**02 可持续困境**

目前项目入不敷出。还是需要寻找可以长久可持续的具体方案。



**02.1 创变局营收**

从创变局的角度来看，冰粉售卖的价格基本与冰粉的成本持平。虽然从总投资来看是亏损，然而，不少工具在后期依旧可以重复利用，反而是一些物料成本，不可重复利用的成本，大体上被 Cover。

从这个角度来看，参与人越多，创变局的零食摊可以成为一个创收的渠道。



**02.2 熟人网络**

另外，本次项目本质上还是一个熟人活动，虽然也有不少生人，比如杨冬，比如羊羊。然而，少量的自然流量还是说明了大家对草台班子项目的不明所以。

从好的方面说，这种不明所以一定程度上也意味着一些说不清道不明的东西，可能只能通过亲身参与去获取，去了解。

从不好的方面说，这种认知与行动的双重壁垒，也正是草台班子项目在现阶段难以向社会铺开，得到认可的障碍。

**03 影响力**

首先，参与活动的人通过实际的链接，一定程度上是有很大收获的。这种收获感更多来源于一种对未来的向往，是一种可能性毒药。比如和黄龙岛谈到理想解决不了问题，能解决问题的是技术。

另外，人与人的链接在草台班子等活动中不一定能深入。相互链接注定是一个双方的行动。比如羊羊她究竟从中学到了什么，和阿飞所感受到的是不一样的。

第三，行动作为方法特别有效。典型案例就是一块钱挑战。一些说不清道不明的东西，通过观察模仿可以非常容易的进行复刻。原本，临时创变局也计划做冰粉尝试，用一块钱挑战类似的办法促成创变，但是却受到场地的限制。

最后，一些原本不认为是草台项目的项目，实际上也有着意想不到的效果。比如身体游乐场的极低成本参与，低投入高产出带来的样板案例，对类似品牌共创活动是有很大借鉴意义的。



**03.1 理论反思**

根据央美社会设计理论，

- [x] 历史作为方法——做真问题：经过实践，草台班子的需求确实存在，它正应对了一些人不明所以，但有所求的状态。并且将有所求转化为具体的行动，产生真正的创变与成长。

  以迷宫为典型，这样的艺术装置一方面作为文化符号可以将当代青年说不清道不明的困境，成为一个可以思考、反思的符号，也同时为这一群形成共同符号、共同困境的人有了可以沟通讨论的共识。

  以黄龙岛为例，虽然她们没有在现场做什么活动，但是她们本身来参加活动的行为就对应了草台班子的理念。并且她们实际上也有所行动。
  
  然而，草台班子所对应的社会问题，并没有得到定义和传播，以至于目前很难得到理解和解决。

- [x] 行动作为方法——真做问题：草台班子的完成度很高，虽然各个小草台各有千秋，但从宏观上看，也确实在不同程度上影响到了个体，并参与行动。

  同样也以迷宫为例，她们实际搭建出了一个迷宫装置，并且通过迷宫吸引了创始人的父母一同参加，还有诸多志同道合的朋友们。

- [x] 设计作为方法——会做问题：草台班子的每一个小草台都在思考如何推进项目完成。包括在群内通过大段富文本的形式直接招募，也包括像即兴话剧这样的临时调整。

  不过，虽然很多项目完成了，依旧有很多项目面临中断和失败的挑战。我们可以说，如果一个项目可以失败，要么它没有在解决一个真问题，要么它可能是一种更自然的理念。如果某个项目不会做问题，事实上，产生问题反而是草台班子应该在事后需要进行抓取分析的重要收获。

- [x] 批判作为方法——反思问题

  也应对了上面的会做问题与真做问题。草台班子或者说个体，往往只会记住其中的好，忽视其中的不好。我们应该如何去反思？

  从创变局的角度，我们观察到，很多项目执行者在最开始就选择把预期降到了最低，以至于一个项目成为了几乎不可能失败的项目。虽然这样的项目对于真正执行时会有极少的负反馈，但是这不利于我们成长和迭代。也很难说我们对于想要解决的问题究竟产生了多少创变？

  以创变局为例，如果只是以观察记录并跟踪草台班子全流程而言，创变局是成功的，创变局跟踪将近10个项目，对其进行记录、访谈、体验。同时创变局也和仅25位人士产生了关系。并且冰粉摆摊也收获好评。

  但是，同样以创变局的媒介部分为例，创变局并没有在明面上创变成功任何一人。有很多创变局能做的，但是并没有去做。比如有人反馈现场很混乱，不知道哪里开始活动了，也不知道活动进展怎么样了，于是很多人在休息区躺着，但是其实创变局原计划搭一个媒体展示，专门用来同步信息，为躺平休息的人提供信息，并促进大家参与活动，而事实上并没有落地。

- [x] 网络作为方法——开放问题

  最后，草台班子需要突破自己的熟人圈子，真正走入社会，让更多人看见，让更多人批评。

根据浙大创新设计方法论，

- [x] 人本：草台班子就是要建立一个失败豁免区，鼓励大家行动，总结失败经验，并促成个体成长。
- [x] 商业：草台班子的商业属性薄弱，不是说草台班子本身薄弱，草台班子本身有尝试收费形成经济的可持续。但是草台内部的很多项目缺乏商业闭环。
- [x] 技术：草台班子的活动缺乏技术，很多技术都没有被提起定义。比如灯光、音响、投影、空调；美工、传播、活动流程等。不过其实拼贴诗是一个技术性活动，可惜其产出没有得到重视。
- [x] 艺术：草台班子本身的艺术性也体现在了假牙和小武提供的内容上了。同样，身体游乐场也为活动增添了艺术的氛围。
- [x] 文化：草台班子在最终的路演上有形成一定的文化，超出预期的部分。不过还不够，依旧有很多人对草台班子的概念模糊，不过这不重要，模糊不等于没有。主办方在未来应该需要有把握模糊的能力。



**04 其他问题回答**

**04.1 草台班子的定义问题**

它不一定要被定义，但一定要在定义的路上。主办方必须要为草台班子抽象的概念把握方向。

**04.1.1 什么是项目？**

技术项目、科研项目、社会项目；**有投入、有产出、有时间、有难度。**

企业项目的立项与验收流程包括：立项会、评审与支持、项目执行与中期评审、项目结项几大步骤。

我自身为个人项目抽象了一个模版：初心、资源、要素和成果。分别对应了产出、投入、时间与难度和产出。

广义的项目，只要走完项目流程，就算是项目；狭义的项目，需要分类讨论。



**04.1.2 有哪些项目不是草台？**

- （当前的）二手书籍：不会失败、不需要努力、缺乏个人的初心
- 身体游乐场：已经是一个完整的项目了。虽然对于参与者而言是一个挑战，不过对于发起人本身不具有什么挑战了。

不适合不意味着不能有。
