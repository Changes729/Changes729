## 游乐能，能源层级（雨希）

- 一次能源（自然能量）：化石燃料、核能、可再生能源
- 二次能源（实际使用的能源）：电能、热能、储能电池
- 三次能源（信息、情绪、数据能量经济）



能源思路：

- 三次能源转一次能源：（尚不存在、厌氧消化、甲烷？）这是真正的回归自然。
- 三次能源转二次能源：发电行为，孩童游玩行为（孩童社交），负面情绪发泄
- 三次能源转三次能源：情绪传递
