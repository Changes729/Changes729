主要目标：将方案落实下来，成熟到马上能落地施工的状态（但是现在处于一个设计阶段）



## 汤湖公园背景资料

- 江城十一园计划
- 中建三局、中建八局（合作完成）
- 汤湖公园（背后资方）形成灯塔，吸引资方。
  - **资金**：1000万，500、300、200万。整体施工。早期设计、设备采购、资源对接、公关费用等。（估计0.6的费用占比）
  - **范围**：没有全案。只提供设计方案，设备怎么布局。规划是我们，设备制造是我们。（视觉、功能、机械设计）水电施工不归我们。
  - **时间**：施工一个月（40天、两个月）
