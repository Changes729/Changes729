## 招投标（资金源）

[中国招投标导航网](https://zgztbdh.com/qgzbpt)

- [浙江省公共资源交易服务平台](https://ggzy.zj.gov.cn/jyxxgk/list.html)：有一些招投标信息
- [浙江省政府采购网](http://www.ccgp-zhejiang.gov.cn/)
- [政府采购云平台](https://www.zcygov.cn/)



- 国家级计划

  - 国家重点研发计划（针对关键技术攻关）
  - 科技型中小企业技术创新基金
  - 国家自然科学基金（青年项目、面上项目等）

- 地方政府科技计划

  各省、市、区都有相应的科技创新扶持项目，比如：

  - 高新技术企业研发补贴
  - 技术改造资金支持
  - 专利申请和成果转化资助

- 地方财政部门支持

  - 
    创业创新补贴
  - 企业研发费用加计扣除（税收优惠）

- 资本类资金

  - **风险投资（VC）**
  - **天使投资人**（早期阶段）
  - **股权融资（创业板、科创板、北交所）**
  - **政府引导基金**
  - **战略投资**（来自大型企业的投资合作）



多数项目**每年固定申报时间**（通常是3月-6月集中申报）

高新技术企业认证

- **可行性研究报告**（市场分析+技术路线+实施计划+风险分析）
- **商业计划书**（财务测算、投资回报、市场占有率预期）
- **知识产权证明**（专利、软件著作权）
- **团队资质证明**（核心人员简历、研发经历、成果）
- **资金预算表**（按设备、人员、研发费用细分）



**地方级项目**

| 项目名称             | 主管部门            | 资金规模                    | 申请要点                                   |
| -------------------- | ------------------- | --------------------------- | ------------------------------------------ |
| 高新技术企业培育资金 | 各省市科技局        | 50万以内，部分地区可达100万 | 申请高企认定；包含研发补贴和申报费用支持   |
| 创业创新补贴         | 地方人社局/科创园区 | 5万~50万                    | 入驻科技园或孵化器即可申请；需要商业计划书 |
| 专利资助资金         | 地方知识产权局      | 几千到数万/件               | 先申请专利，再向地方申请资助               |
