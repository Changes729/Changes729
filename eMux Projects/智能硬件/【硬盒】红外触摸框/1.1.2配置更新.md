# 配置更新

## 需求

在现有工程基础上，支持

- TUIO Server 配置
- 触控范围大小配置（映射关系）



## 资源

当前已知的修改项主要为软件更新和硬件更新。

其中软件更新包括了：

- **TUIO配置**：当前触控协议通过 TUIO 发送。
- **触控范围配置**：TUIO也需要一个范围，才能进行映射
  - 梯度TUIO映射：因为环幕融合存在梯度问题，所以可能需要支持梯度映射
- 算法速度提升：通过更新扫描算法提升识别效率
- 限制识别点数：点数多了系统也会卡死
- 误触过滤：大面积、小坏点需要识别且过滤

硬件更新包括了：

- USB防静电：现在主控设备USB通信很容易断掉，推测有可能是静电导致的击穿。
- USB供电：现在12V供电是通过导线引出的，尝试直接USB引入。
- 红外灵敏度提升：思考更换红外接受管、或者变更三极管，从而提高上升、下降时间。
- CANBUS支持：支持主从通信
- 板对板通信接口更新：更换接口，优化当前btb强耦合的问题

**01 具体映射算法**

假设，全屏幕呈矩形，高宽为 H、W。

触摸框呈矩形，偏移位置为 x、y，长度为h，w。那么，偏移量为：

$$offset_x = x / W$$

$$offset_y = y / H$$

映射比为：

$$zoom_w = w / W$$

$$zoom_h = h / H$$

> 获取的信息，全屏幕：11520*1200；最终剩余1110画面未使用
