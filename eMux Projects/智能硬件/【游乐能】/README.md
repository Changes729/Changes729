# 游乐能

## 游乐能核心特色

- 玩乐性与全⺠参与： 创始⼈强调，产品⾸要条件是“超好玩”。
- 能量与价值的转化： 游乐能的核⼼在于将玩耍产⽣的能量进⾏收集并转 化为有价值的电⼒。
- ⾏为能源经济体： “游乐能”不仅仅是设备供应商，更是“⾏为能源经济⽣态的创造者”。
- 模块化与快速部署
- 创造性⽣产⼯具： “游乐能”不仅能发电，还能创造⽣产⼯具。
- 环境治理新范式： 游乐能还探索了通过玩乐⽅式进⾏环境治理。



## 游乐能初心使命

创造流动的经济体与爱的技术架构

- 推动全⺠可持续发展
- 构建⾏为能源经济体
- 创造“爱在其中流动的技术架构”
- 融合多元领域
- 响应联合国可持续发展⽬标



## 游乐能，能源层级

- 一次能源（自然能量）：化石燃料、核能、可再生能源
- 二次能源（实际使用的能源）：电能、热能、储能电池
- 三次能源（信息、情绪、数据能量经济）



能源思路：

- 三次能源转一次能源：（尚不存在、厌氧消化、甲烷？）这是真正的回归自然。
- 三次能源转二次能源：发电行为，孩童游玩行为（孩童社交），负面情绪发泄
- 三次能源转三次能源：情绪传递



## 技术路径图（2025-12-27）

**01 自然能源与储能模块**

负责接触、成为或回馈为自然能源的模块。

- 能量接触：是指如何接触（感受）到这样的能量。任何利用率不高的自然能量状态都需要接触。对人有危险的自然能量称为超能。

  比如，化学能甲烷的自然状态很难高效利用。但是它可以存在在自然。

- 能量存储：是指如何将某种类型的自然能量，转化为其他可以存在时间更长的能量。

- 能量回馈：是指人类如何产生能量回馈自然，此时人作为中介产生能量（但往往也需要其他物质支持）。

  此时的回馈，往往以自然中的生物为对象，比如植物、动物。（虽然说到底还是为了人类自己，但也许转折点就在人类是否会为了「无意义」而活着）

| 能源类型         | 能量接触                             | 能量存储              | 能量回馈 |
| ---------------- | ------------------------------------ | --------------------- | -------- |
| 辐射能（太阳能） | 紫外线变色、晒背（升温）、太阳能电板 | 光合作用              |          |
| 风能             |                                      | 风车发电机            |          |
| 潮汐能           |                                      | 潮汐发电机            |          |
| 电磁能           | 雷电（超能）、静电                   | 电容存储/化学电池存储 | 电磁感应 |
| 化学能           | 沼气                                 | 甲烷                  | 厌氧发酵 |



**02 能级转换模块（交互模块）**

主要实现各种不同能级的转换。比如将三次能源转换为二次能源。

| 情感类型         | 行为方式 | 能级转换                       |
| ---------------- | -------- | ------------------------------ |
| 焦虑             | 占卜     | 三次能源转二次能源（转经筒）   |
| 热爱自然         | 养植物   | 三次能源转一次能源             |
| 运动满足与自由感 | 骑行     | 三次能源转三次能源（奇迹生花） |

| 能量类型       | 能量接触 | 能量存储 | 能量回馈 |
| -------------- | -------- | -------- | -------- |
| 焦虑能         | 占卜仪式 | 电能     | 希望能   |
| 自由能（运动） | 骑行     | 电能     | 好奇能   |
