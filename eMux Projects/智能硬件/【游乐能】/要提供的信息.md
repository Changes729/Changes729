电子信息专业背景，曾在互联网公司（VoIP）任嵌入式软件（Linux）工程师，后在创意展厅公司任嵌入式工程师（软硬件）。我认为游乐能兼具社会与技术视角，并以具体的行动推动社会变革，同样是本人在追寻和努力的方向。希望加入游乐能，和游乐能一起影响世界。目前主要负责支持游乐能业务主线的技术实施、研发与落地支持，包括了智能硬件和物联网范畴。



二、关键能力

主要能力覆盖在软件开发与嵌入式开发。主要语言 C/C++ 用于嵌入式和后端开发、TS 用于前端开发。主要开发环境为 Arch Linux。

C/C++ 嵌入式涉及 GD32（STM32）、ESP32 和 ARM Linux。

后端开发涉及 Linux APP、SDL（LVGL）、数据库操作如MariaDB（MySQL）、Valkey（Redia）、InfluxDB、SQLLite

前端开发主要为 React 框架。

Arch Linux 装机管理和服务部署运营等。

硬件开发主要使用 KiCAD，配合结构设计的软件为 FreeCAD 和 Blender。切削工艺有时会使用 OpenSCAD。

除此之外，熟悉设计思维，比较宽泛的工作内容使得具有一定跨工种协同经验。
