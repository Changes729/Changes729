# 电表信息采集

## 需求和愿景

这是个人数字化方向的第一个项目。项目需求为电表的智能化采集，采集的用电信息需要和操作配合，从而提高机器运作效率。

效率提升的指标包括了电费的降低，设备运作周期的缩短，以及故障率的降低等。

具体需求如下：

支持工厂内多个设备的用电量采集。

- 提供灵活实时的用电数字化记录。

- 数字化记录需要将功率与设备运作，设备动作进行锚定。

- 锚定后的数据可以用于技术分析，降本增效。

隐藏的需求为：

- 如何为一个旧的，只有供电网络的工厂提供数字化基础设施？

- 考虑未来 PLC 设备的介入

考虑到最终的目标是将本增效，但是实际上很难对生产机器本身进行优化，因此，这里的降本增效更多的是配合策略部门更好的去验证材料配比，辅助他们进行决策。

虽然未来可能可以借用AI的方式辅助决策，可是当前数字化的阶段还是以信息的收集为主。



## 能力与资源

数字化记录相关：

- 有云服务器、本地服务器搭建经验；
  但是不清楚当前行业主流的解决方案架构，以及内在的考量

- 了解云后端API，具有编写后端API的经验（GoLang）；
  但是对于网络安全部分不太了解。

- 具有嵌入式接口开发的能力；
  但是没有设计过485的电路，也不确定如何上传数据；

- 了解数据存储需要数据库支持；
  但是不太了解具体的数据库选型。

网络基础设施相关：

- 有网络布线设计的经验；
  但是缺少工业网络设备选型经验。

工厂环境的不足，可以与工厂领导进行沟通解决。而具体的工厂改造方案，则需要各部门协同决定与实施。



## 要素和路径

基础合作办法：

- 一个月至少一次的线下工作汇报

- 项目文档留档，且通过网页定向开放

- [ ] 不太确定甲方的时间限制，资金投入和人员支持情况

项目阶段：

1. 项目意愿沟通：在此重申当下阶段目标，未来效用，当下阶段和下一步工作计划

2. 沟通工作所需资源以及阶段工作目标

3. 产出完整的工作计划与工作安排，进行项目多方同步

4. 同步后进入工作实施阶段；对关键结点和工作内容进行把控和记录。阶段成果反馈与留档

5. 阶段测试、内部验收

6. 项目验收

## 成果和不足

### 项目阶段与项目目标

项目主要分为两个大阶段：数字化基础设施建设阶段，电表信息数字化建设阶段。

数字化基础设施建设阶段主要目标是<u>在公司内部建设符合公司数字化发展需要的基础设施</u>，其中具体包括：

1. 中心机房：处理器电脑、RAID数据库、交换机

2. 网络拓扑

电表信息数字化建设阶段，主要目标是<u>搭建本地服务，提供数字化的电表信息数据采集和API</u>，其中具体包括：

1. 485通信，电表信息采集
   
   - 可能的硬件研发

2. 本地服务建设：数据库、后端和前端
