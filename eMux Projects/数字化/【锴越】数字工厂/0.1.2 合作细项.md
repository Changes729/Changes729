# 合作细项

## 愿景和需求

与锴越在数字化基础设施改造、智能电表信息采集、流程控制系统和MES系统建设的大方向上达成一致。其中：

1. 数字化基础设施改造，具体包括网络环境改造和网络机房建设。其中

   - 网络环境重点在网线布置和配合网络的弱电改造

   - 网络机房建设在配合网络的网络基础设备，和用于后续智能电表信息采集用的电脑和机柜安装

2. 智能电表信息采集，具体包括实施计划，以及需要配合的设备测试、安装细节。

3. 流程控制系统（Distribute Control System，DCS），指在 MES 前级，通过中心化的系统对全企业的自动化设备进行统一管控，是 MES 系统的基础功能；最终目标还是向着 MES 系统前进的

4. 明确纳入公司年度发展计划、项目执行的配合的人员以及项目立项与同步会。



重点讨论内容在【1】和【4】。  



## 能力与资源

- 有网络部署的经验和知识



## 要素和路径

- 需要进一步阐明网络建设步骤（文档化）
- 需要进一步阐明智能电表信息采集的步骤（了解）
- 需要同步 DCS 作为 MES 的前置（了解）
- 需要纳入公司发展计划（明确）
- 需要明确配合执行的人员（明确）
- 需要立项与同步会（关键阶段）
