# 工厂终端扫描

## 数字化需求简记

- 每一台产线有一个电表
- 大型流水线要小心人被滚筒卷入
- 其次要注意生产过程中的高质量生产（监控流水线异常）



## 接入终端类型

1. 电表：所有大型设备一个设备一个电表
2. 摄像头
   - 用工安全
   - 自动化产线监控
   - 物料监管
3. PLC 设备数字化接入
