# 抄表系统说明文件

抄表系统网页在内网：http://192.168.10.111:8080，没有密码，页面内容如下所示：

![](file:///home/asuki/Resource/eMux/%E9%94%B4%E8%B6%8A/04%20CRM%20%E7%B3%BB%E7%BB%9F/%E6%88%AA%E5%B1%8F2025-10-28%2011.31.44.png)

其中，`下载` 可以直接下载为 CSV 文件。

`设备名称` 与 `设备倍率` 的内容可以修改，点击 `保存设备信息` 的按钮即可。

`瓦数` 表示电表当前的读数。

`调整功率` 为设备读书 乘以 设备倍率后的真实值。



抄表系统默认**在设备在线时会自动抄表**。有些设备的电源会和动力开关的总闸共同开关。可以认为，如果某个设备在长期内没有启动，那么其对应的抄表系统也不会自动启动。

没有用电就不会抄表，只要用电就会自动抄表。`最后采集时间` 呈现了设备最新采集的电表数据，即使有设备显示 7天前采集，但是这也意味着 7天内 电表对应的设备没有启动过。



若设备启动，但是依旧没有读数，则为异常情况，请联系工程师进行问题排查。
