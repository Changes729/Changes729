MariaDB

- 用户表
  - id：小程序 ID
  - nickname：昵称
  - ~~avatar：头像~~ 省略，直接路径匹配
- 日签表
  - pid：日签ID
  - id：用户ID
  - datetime：发布时间
- 访客表
  - id：用户ID
  - pid：访客日签
  - datatime：访客时间
- *骑行表*
  - *rid：骑行记录 ID*
  - *id：用户ID*
