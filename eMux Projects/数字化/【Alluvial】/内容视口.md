# 内容视口

基本来说，我们希望我们的输入就是我们的输出。所以类似的 Typora 软件实现的功能就非常好用。但是 Typora 对底层数据的管理不足，使得各种软件的开发都出现了细粒度瓶颈。



- 统一内容输入端口
- 统一内容输出端口
- 内容自动细分与管理



## 时间视口

- 愿景域（遥远的未来）
- 计划域（不远的未来）
- 执行域（当下）
- 补充域（不远的过去）
- 历史域（遥远的过去）



## *WYSIWYG editor* 

**01 开源编辑器整理**

**01.1 选择的编辑器**

Tiptap(ProseMirror)

ProseMirror 支持 Markdown 格式。

有成熟社区支持。



**01.2 需要关注的编辑器**

| 编辑器        | 技术底层                                     | 架构类型                  | 数据模型         | 特点                                          | 缺点                                      |
| ------------- | -------------------------------------------- | ------------------------- | ---------------- | --------------------------------------------- | ----------------------------------------- |
| **Tiptap**    | 基于 [ProseMirror](https://prosemirror.net/) | 富文本 + 可拓展块结构     | Document Node 树 | 高度可自定义，支持协作（Y.js 集成），成熟生态 | 学习成本高，插件精通需要 ProseMirror 知识 |
| **Editor.js** | 原生 JS + 插件系统                           | 块级编辑器（Block-based） | JSON blocks      | 输出结构化数据（适合 CMS/文章存储）           | 不适合传统长篇富文本，缺乏协作            |
| **Slate.js**  | 基于 React 的纯编辑内核                      | 低层编辑器框架            | JSON + Immutable | 非常灵活，适合自定义业务                      | 需要自己处理协作、历史记录等高级功能      |

| 库                  | 启动速度       | 大文档性能       | 协作延迟（WebSocket+Y.js） | 前端内存占用 |
| ------------------- | -------------- | ---------------- | -------------------------- | ------------ |
| Tiptap(ProseMirror) | 中等（~200ms） | 稳定，性能好     | 低延迟（~50ms）            | 中等         |
| Editor.js           | 快（~80ms）    | 块较多时性能下降 | 无内置协作                 | 低           |
| Slate.js原生        | 因自行优化而定 | 性能取决于实现   | 需自己集成                 | 高           |



| 编辑器            | 技术底层              | 原因                                     |
| ----------------- | --------------------- | ---------------------------------------- |
| **Yoopta-editor** | 基于 Slate.js + React | 社区较新，并且使用 Slate.js 值得参考     |
| **CKEditor 5**    | 富文本 + 类块支持     | 学习曲线高，自定义成本大，大块富文本处理 |



**01.3 不考虑的编辑器**

| 编辑器      | 技术底层             | 放弃原因                           |
| ----------- | -------------------- | ---------------------------------- |
| **TinyMCE** | 原生 JS              | 不适合块式编辑                     |
| **Quill**   | 原生 JS + Delta 格式 | 定制块能力差，不好做 Notion 式编辑 |
