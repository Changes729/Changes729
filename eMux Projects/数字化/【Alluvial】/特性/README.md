# 基本原则

替代人的重复劳动。比如，新建文件夹、重复的标题。反复匹配。



# 产品特性

【Ver 1.0】WYSIWYG 编辑器基础特性

- [【0】](./Ver 1.0.0 基本内容.md)：基本编辑器支持标题、文本、List和Todo（同时也支持上了完全普通的文本）
- [【1】](./Ver 1.0.1 Alluvial Basic.md)：在基础编辑器基础上，支持多媒体数据和块数据（现代编辑器），支持图片、代码块、超链接，同时支持了很多自动识别的功能。比如超链接转换、图片转换。
- [【2】](./Ver 1.0.2 Block Support.md)：在现代编辑器的基础上，实现更丰富的块内容支持。以支持未来类似 VSCode 风格的内容提示。

【Ver 1.1】「潮汐」，面向个人日常记录的工具。通过强时间观念的呈现方式，有效串联起当下、过去和未来。

- [【0】](./Ver 1.1.0 潮汐（Tidal）.md)：日程化，流式日志。记录一切今日的收获，所思所想。
- 【1】：标签化，后台系统支持。灵活高可用的标签系统。
- 【2】：项目化，行动驱动。可以抛出需求，也可以收受需求。
