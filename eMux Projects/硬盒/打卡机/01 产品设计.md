# 产品设计

## 产品定位

通用形 RFID 开发板

**01 功能设计**

**01.1 支持 REST API**

允许第三方应用通过 REST API 开发软件，具体功能包括：

- 刷卡反馈功能
  - HTTP POST
  - MQTT（付费）



**01.2 支持 Web 自定义**

- 允许自定义网页（上传网页包）



**01.3 支持系统更新**

- 提供默认网页支持基础配置
  - 静态IP配置
  - mDNS（付费）
