# 新合作模式设计

## 需求和愿景

更新于硬盒合作的新范式。现在的关系是劳务报酬的关系，但是项目数量不清晰、权责不清晰使得现在发展受限。

所以这一步的目标，是在当前已经沟通好的基础上，为未来商业模式拓展打下坚实的基础。

重点在明确责任义务和经济的关系。



## 能力与资源

**01 底线协议**

现在双方已经沟通，底线是 6k 月劳务费。可以往上加。



**02 项目扫描**

不仅仅包括了项目，其实还包括产品。

现在运行的项目——无界宇宙和触摸框。



**03 当前问题**

- 研发费用不明确
- 收入较低，动力不足
- 项目范围不明确

- 从产品维护的角度建立合作

**02 商业模式设计**

现在双方的关系：

1. 产品研发：主要指一些硬件产品的研发，从无到有的过程。需要满足公司的设计需求。
2. 技术实施/产品实施：主要指一些技术功能的交付，这些技术功能不一定要自研，也可以选择对外采购。
3. 技术运维：对于出现问题的产品进行维护。
4. 技术支持：对于技术可行性进行研究。
