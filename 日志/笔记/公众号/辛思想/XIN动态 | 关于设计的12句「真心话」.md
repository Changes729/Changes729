# XIN动态 | 关于设计的12句「真心话」

## 摘记

- [ ] 别在比你高很多段位的人面前装聪明——在他们眼里，你是透明的。

  人为啥会装聪明呢？

- [x] 真正的贵人其实是你自己。不要向外苦苦追寻，当你选择用真心去对待遇见的每一个人时，这种特质会被他人敏锐地感知到。贵人从来不是找来的，而是被你自身的磁场吸引来的。

- [x] 无论你是T型还是 $\pi$型人才，核心护城河是保持对外部世界的关心。这种对'天下事'的敏锐度，才是支撑你不断自我更新的方向感。

- [ ] 做文献综述，绝不仅仅是为了去复述别人已经讲过的老话。它的真正目的是：I'm looking for a place that is not yet occupied. 去精准地寻找并开发那个尚未被开拓的思想高地。

  不会文献综述。


- [ ] 真正的批判性思。维，永远是对事不对人的。我们提出批评，绝不是为了在口舌上争个对错输赢。它的前提是克制与包容：首先要去尊重、去理解并认可对方已经占领的立场，然后在这个基础之上，再去寻找并构建属于你自己的全新视角。

  目前还做不到。
  
- [ ] 决定一件事是否有意义的，是你的使命与价值观。当'意义'沦落为一种商业包装的手段时，它本身就已毫无意义。

  不太认可。意义是被赋予的。人生的首要意义是生存。商业是一种生成意义泛化。

- [x] 别对 AI 感到焦虑，坦然把它当成普通工具去驾驭。它能极大地替代纯劳动力(Labor)，但永远无法替代人类真实的行动与意图(Action &Intention)。

  AI 是拙劣的模仿者。但是和普通的模仿者不同，它模仿的是全人类。

- [x] AI 的表现上限，取决于与它协作的你。近朱者赤，近墨者黑。

- [x] 无论是最前沿的基础科学，还是今天火热的人工智能，只要技术最终是为人类服务的，它就永远绕不开对'人'的深度理解。

- [x] 不管你学的是哪个细分专业，对人的理解永远是设计的核心。去学会察言观色，去真正用好你的同理心，去感受他人的情绪与需求。这不仅仅是做设计的必修课，更是你步入社会、与真实世界打交道最好的心理训练

- [ ] 设计思维的本质，是在无穷的变量与开放的结果中，找寻那条最合理的因果逻辑。

- [x] 懂设计的同学，未来不妨去试试做产品经理。你会恍然大悟:做产品经理，其实才是把你在学校里学到的那个'大设计'真正放进商业世界里去落地。
