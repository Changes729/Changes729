# 睡前做这3个动作，能改善睡眠时长！很多人还不知道

## 关键词

- **深蹲：**模仿坐椅子的动作，膝盖不超过脚尖。
- **提踵：**站立抬起后脚跟，使小腿肌肉收缩，然后脚跟慢慢回到地面。
- **提膝展髋：**站立膝盖抬高，直腿髋关节伸展。
