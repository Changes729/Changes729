**01 KG 常见的应用场景**

- 搜索：智能搜索、智能问答、知识导航、推荐系统

- 社交：个人信息管理/检索

- 辅助决策（知识库）：营销决策、产品研发、财务法务、反欺诈

  > 文中提到的反欺诈意味着一种零知识证明。



**02 KG 面临的困难和挑战**

困难

- 数据的可访问性
- 数据的可发现性
- 数据的深层关系：依靠人力无法发现在数据中隐藏的众多关系，通过推理规则可以发现隐藏的很深的联系
- 领域知识的集成
- 策略的生成

挑战

- 非结构化数据
- 数据质量和数据规模
- 知识表示方法
- 大规模KG可视化
- 深度学习的不可解释性



**03 知识存储方式**

数据库管理系统

- MySQL：结构化数据
- Bigtable：非结构化和半结构化大数据

开放知识库

- OpenCyc
- WordNet：最著名的因为电子词典和本体知识库
- ConceptNet：尝试数据库
- ~~Freebase~~
- Wikidata
- DBpedia：多语言综合性知识库。指数据库版本的 Wikipedia
- Yago：集成了 Wikipedia、WordNet、GeoNames
- BabelNet：类似 WordNet 的多语言词典知识库，目标是解决 WordNet 在非英语语种中数据缺乏的问题。
- Nell：卡内基梅隆开发的知识库，本身是一套学习系统。
- Concept Graph
