# Division of maps: Isomorphisms

# 映射的划分：同构关系

## 关键词

- 同构（isomorphism）或可逆映射（invertible map）：A map $f: A \to B$  is  called an isomorphism, or invertible map, if there is a map $g: B \to A$ for which $g\circ f = 1_A$ and $f\circ g = 1_B$
